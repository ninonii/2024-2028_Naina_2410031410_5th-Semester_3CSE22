## 🚀 Project Overview
The **Heart Failure Risk Prediction Web Application** is a machine learning-based diagnostic tool developed to assess a patient's risk of heart failure based on 11 clinical attributes (e.g., Age, Resting BP, Cholesterol, Max HR). The classification pipeline utilizes a Logistic Regression model trained on the Kaggle Heart Failure dataset. The project demonstrates full-stack integration, combining serialized scikit-learn models with a Flask web server and a responsive Tailwind CSS frontend interface.
